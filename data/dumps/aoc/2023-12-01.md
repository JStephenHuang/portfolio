## Day 1 — Calibration values

This is a **mock journal entry** showing how a short Advent of Code write-up could look.

### Part 1

The first pass scans each line, keeps the numeric characters, and combines the first and last digits into one calibration value.

```ts
const calibrationValue = (line: string): number => {
  const digits = [...line].filter((character) => /\d/.test(character));

  return Number(`${digits[0]}${digits.at(-1)}`);
};
```

The important edge case is a line containing only one digit. In that case, the same digit becomes both the first and last value.

### Part 2

Part 2 also recognizes spelled-out digits such as `one`, `two`, and `three`. Overlapping words need special attention—a value like `twone` contains both `two` and `one`.

> Mock takeaway: walking forward one character at a time is safer than replacing complete words.

| Input | First digit | Last digit | Value |
| --- | ---: | ---: | ---: |
| `1abc2` | 1 | 2 | 12 |
| `treb7uchet` | 7 | 7 | 77 |
| `two1nine` | 2 | 9 | 29 |

## Day 2 — Cube game

This mock solution parses game records and checks whether every revealed set is possible with a limited collection of cubes.

### Part 1

I represented each reveal as a small object so the validation rule stays readable:

```ts
interface Cubes {
  blue: number;
  green: number;
  red: number;
}

const limit: Cubes = {
  red: 12,
  green: 13,
  blue: 14,
};

const isPossible = (reveal: Cubes): boolean =>
  reveal.red <= limit.red && reveal.green <= limit.green && reveal.blue <= limit.blue;
```

- Parse the game identifier.
- Split the record into individual reveals.
- Keep games where every reveal is within the limit.
- Sum the identifiers of the remaining games.

### Part 2

For each game, the minimum required bag is determined by the largest observed count of each color. The power is then `red × green × blue`.

```ts
const power = ({ red, green, blue }: Cubes): number => red * green * blue;
```

The parsing code can stay unchanged; only the final reduction needs to be different.

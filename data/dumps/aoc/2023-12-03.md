## Day 3 — Engine schematic

This is another **mock entry**, this time for a grid-based problem involving numbers and nearby symbols.

### Part 1

The main challenge is remembering that a number can span several columns. I first collect the complete number and its coordinate range, then inspect the surrounding rectangle for a symbol.

```ts
interface NumberSpan {
  row: number;
  start: number;
  end: number;
  value: number;
}

const isSymbol = (character: string): boolean => character !== "." && !/\d/.test(character);
```

### Part 2

A gear is an asterisk touching exactly two numbers. Instead of searching outward from every number again, I map each gear coordinate to the numbers that touch it.

```ts
const gearRatio = (values: number[]): number | null => {
  if (values.length !== 2) return null;

  return values[0] * values[1];
};
```

This keeps the final step simple: discard non-gears and sum the remaining ratios.
